No clutter, no unnecessary steps — just pick a course, drag to set your score, and play.

## ✨ Features

-  Track scores for full disc golf rounds, hole by hole
-  Multiple built-in color themes
-  Detailed course & hole statistics (best / average / worst)
-  Simple, drag-to-set score entry — fast enough to use mid-round
-  Create and manage your own custom courses with per-hole par
-  Automatic round history, saved locally
-  Resume an in-progress round at any time
-  Lightweight, fast, and clean UI — no ads, no bloat, no unnecessary features

## 📦 Installation

### Option 1: Download APK (Free)

1. Go to the **[Releases](../../releases)** page
2. Download the latest `.apk` file
3. Transfer it to your Android device (if downloaded on a computer)
4. Open the file and install it

> ⚠️ You may need to enable **"Install from unknown sources"** in your device settings, since the app isn't distributed through the Play Store.

**Requirements:** Android 8.0 (Oreo) or newer is recommended.

## ❓ FAQ

**Is Discly free?**
Yes, the APK is free to download via GitHub Releases. A paid Google Play version will be available later to support development.

**Does it require an internet connection?**
No, Discly works fully offline. All course and score data is stored locally on your device.

**Can I use Discly's code in my own project?**
No — see the [License](#-license) section below. The source is visible for transparency, not for reuse.
