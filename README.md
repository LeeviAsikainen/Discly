# Discly

![Android](https://img.shields.io/badge/platform-Android-green)
![Build](https://img.shields.io/badge/build-Automated-blue)
![License](https://img.shields.io/badge/license-Custom-lightgrey)

Discly is a simple and fast Android app for tracking disc golf scores.

APK builds are automatically generated and available for download via GitHub.

---

## 📱 Features

- Track scores for disc golf rounds
- Simple and clean UI
- Lightweight and fast
- No unnecessary features

---

## 📦 Installation

### Option 1: Download APK (Free)

1. Go to **Releases**
2. Download the latest `.apk`
3. Install on your Android device

> You may need to enable *"Install from unknown sources"* on your device.

---

### Option 2: Google Play (Paid)

Support the project by purchasing the app on Google Play (coming soon).

---

## 🛠️ Development

This project uses:

- Android (Java/Kotlin)
- GitHub Actions for automated APK builds
